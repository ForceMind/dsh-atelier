## 四个概念，不混为一谈

1. **渠道回退**：适配器 `providers.<route>.reasoning`；显式调用档位通常优先于它。
2. **模型支持档位**：`reasoningEfforts`，声明选项和 wire 映射，不等于当前选择。
3. **模型默认档位**：Better Reasoning Effort 的 `defaultEffort`；已有模型行选择器，随原卡片 Save/Cancel 提交／撤销草稿。不是渠道设置。
4. **当前选择**：`ModelSelection.reasoningEffort`，影响后续请求。原插件还保存会话内切模记忆；配置的模型默认可影响新会话。

## 不提供虚假的“仅当前会话”按钮

DSH 0.2.1-rc.3 的正式 `sessionController.selectModel` 会安装会话选择，随后异步调用 `agentDefaultModel.saveSelection` 保存部署默认。当前服务没有 `persistDefault:false`、`sessionOnly` 或专用恢复继承接口。

因此本次不新增声称严格隔离的“仅当前会话覆盖／恢复渠道默认”写按钮。不能先改默认再写回旧默认来模拟隔离（与其他会话、保存队列竞争）。不修改安装包、不 monkeypatch 原选择器，不复制另一份配置存储。

原编辑器的 Reset 是撤销待保存编辑；清除插件模型默认会回到其记忆链，不等于持续继承渠道默认。省略 `reasoningEffort` 调用 selectModel 仍会解析默认并持久化，不应命名为“恢复继承”。

## 后续整合依赖
