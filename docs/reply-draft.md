# 回复草稿（不自动发送）

## 使用

助手回复结束后，保持输入框为空，点击输入框中的“回复草稿”。插件根据**最后一条助手文字消息**生成一句或两句用户回复，填入输入框；发送必须由用户自行点击。

这是一次独立模型调用，可能收费，使用该助手消息记录的渠道／模型，不改变当前会话选择。最多1024个输出tokens（受模型上限约束，包含模型可能使用的思考预算）、最长30秒，不传工具；只发送上一条助手的文字，不发送 reasoning 块、文件、图片、工具结果或完整历史。不要用它替代审批、选择或事实确认：草稿可能出错，应自行审阅。

## low 思考档位

按用户最新选择，本次调用明确选择 `reasoningEffort: low`，且模型信息必须声明支持 low。low 是低强度思考，不是关闭思考。请求准备后再次核对 low；允许返回思考片段，但只提取文字草稿，绝不把 reasoning 块填进输入框。不改原模型能力声明，不回退到 high 或默认档位。

如果切换了当前会话模型，下一次草稿仍使用最后助手回复的来源模型，直到新模型真的产生新的助手回复。若来源模型不支持 low，需要先使用支持 low 的模型得到新回复，再生成草稿，而非仅切选择器。

## 输入保护

- 已有文字（含空格）、引用、附件、输入法合成、正在运行或有待发送消息时不可生成。
- 使用宿主 `captureInsertion`／`insertText` 版本校验，不调用 `setDraft` 或发送接口。
- 生成期间输入、附件、会话、编辑器身份等变化时不覆盖输入；展示只读结果供手动复制。插件卸载／会话变化使旧结果不能再写入。
- Host 同时检查 Agent 空闲、最后消息身份及来源；发生新回复／会话变化则丢弃。每会话只允许一次，最多四个并行草稿请求。
- 模型截断、工具调用、空回复、错误完成原因均拒绝。

## 记录与统计

草稿不是已提交的会话消息，也不产生一轮聊天。当前实现不把它加入会话事件或会话usage统计，因此底栏会话总费用不含这次独立调用；真实API账单可能包含该费用。若插件开启请求正文审计，全局 llm 观察器仍可能记录这次独立请求；不要将审计文件直接公开。

## 已验证

2026-11-04 rc.5隔离Host，用本地无网络适配器完成一条助手回复后点击生成：输入框出现预期草稿，聊天记录无自动新增用户消息，原模型选择仍为High。适配器读回草稿调用 `off`、maxTokens256、无工具、无会话ID；普通会话调用仍是原high。输入非空时按钮禁用。

改为low后主插件119项测试通过，包含6项UI模拟测试与5项Host/domain草稿测试（新增思考片段不混入草稿回归）。原off浏览器验收为历史记录，不能冒充low真实渠道验收；本次未自动发起真实付费请求。模拟覆盖已输入／输入后清空／附件变更／IME／会话切换／最终版本校验失败。实际生成中编辑、附件和IME竞态尚未全部浏览器验收。一次自动化改写输入检查因焦点变更未执行，不计为通过。没有调用真实付费API。
