# Mini Saturn

This plugin requires the proposed `conversation.chat.running.icon` slot. Stock Harness 0.2.1-rc.3 does not declare it; installing this plugin there does not replace the whale. No CSS overrides, DOM replacement or ChatFlow substitution are used.

The decorative icon occupies 14×14 CSS pixels, inherits the running text color and rocks gently every three seconds. Reduced motion renders it still. The owning RunningStatus retains text, elapsed time and aria-live. Disabling this plugin restores the built-in whale registration on the patched build.

Not installed into the current application. Validate running state, reduced motion, light/dark themes and disable/restore on the approved patched build before daily use.
